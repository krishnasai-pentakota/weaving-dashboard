# weaving-dashboard
End-to-end manufacturing data platform featuring a Python/SQL ETL pipeline, automated data quarantine guardrails, and a live Stream-lit operational dashboard.
An AI-assisted manufacturing data platform that consolidates unreliable multi-workbook production records into a governed PostgreSQL warehouse. Features include daily ETL with idempotent UPSERTs, automated data-quality quarantine, and a Streamlit dashboard reconciling 44.8 million yards of historical production data.
